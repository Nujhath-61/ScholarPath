Sure! Let's go through the animation-related properties from the CSS above in a very simple way.
1.transition
```css
transition: 0.3s;
```
What it does:
Makes changes happen smoothly instead of instantly.
Without transition:
Hover button → color changes immediately.
With transition:
Hover button → color changes gradually over 0.3 seconds.
Example:
```css
button {
    background: blue;
    transition: 0.3s;
}
button:hover {
    background: red;
}
```
When you move the mouse over the button, the color slowly changes from blue to red.
---
### 2. `:hover`
```css
button:hover {
    background: #0056b3;
}
```
**What it does:**
Applies styles when the mouse is over an element.
Example:
```css
button:hover {
    transform: scale(1.1);
}
```
The button becomes 10% larger when hovered.
---
### 3. `:focus`
```css
input:focus {
    border-color: blue;
}
```
**What it does:**
Applies styles when the user clicks inside an input or select.
Example:
```css
input:focus {
    border-color: green;
}
```
When you click the input field, its border turns green.
---
### 4. `box-shadow`
```css
box-shadow: 0 0 5px rgba(0,123,255,0.3);
```
**What it does:**
Adds a shadow around an element.
Parts:
``css
box-shadow: horizontal vertical blur color;
```
Example:
```css
box-shadow: 0 0 10px gray;
```
Creates a soft gray glow around the element.
---
### 5. `transform`
This property is often used in animations.
####Make bigger
```css
transform: scale(1.1);
```
110% of original size.

#### Rotate

```css
transform: rotate(45deg);
```

Rotates 45 degrees.

#### Move

```css
transform: translateX(20px);
```

Moves 20 pixels to the right.

Example:

```css
button {
    transition: 0.3s;
}

button:hover {
    transform: scale(1.1);
}
```

The button smoothly grows when hovered.

---

### 6. Real Animation with `@keyframes`

Example:

```css
@keyframes bounce {
    0% {
        transform: translateY(0);
    }

    50% {
        transform: translateY(-20px);
    }

    100% {
        transform: translateY(0);
    }
}

button {
    animation: bounce 1s infinite;
}
```

**What happens?**

* Starts at normal position.
* Moves up 20px.
* Comes back down.
* Repeats forever.

---

### Quick Summary

| Property     | Purpose                               |
| ------------ | ------------------------------------- |
| `transition` | Makes changes smooth                  |
| `:hover`     | Styles when mouse is over element     |
| `:focus`     | Styles when element is clicked/active |
| `box-shadow` | Adds shadow                           |
| `transform`  | Move, rotate, resize elements         |
| `@keyframes` | Creates custom animations             |
| `animation`  | Runs a keyframe animation             |

A good next step is to learn these 3 first:

1. `:hover`
2. `transition`
3. `transform`

Once you understand those, CSS animations become much easier.
